# SkateOrDye
skatepark-themed color check for your terminal. 


Skate or Dye banner: a rainbow skateboard deck that shows your terminal type, width and how many colors it supports.


The Deck Wall: your 16 basic colors, each drawn as a little skateboard deck with wheels and labeled with its number and name.


Trick List: text styles shown as skate tricks. Ollie is bold, Kickflip is italic, 50-50 Grind is underlined, Fakie is reversed and Bail is struck through.


The 216 Skatepark: the full 256-color palette laid out as a grid.


Grip Tape: the 24 gray shades.


Sunset Session: a smooth 24-bit color sunset. If your terminal can't show full color, the script tells you.


Drop In: a skater rolls across the screen leaving a rainbow trail and ollies over a traffic cone.


It ends with a random skate quote.

To run it:


chmod +x skatecolors.sh


./skatecolors.sh        # full session


./skatecolors.sh -n     # skip the animation


works on Debian/ Ubuntu
